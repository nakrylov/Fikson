# Fixon (Фиксон)

**Фиксон** — B2B SaaS-система для фиксации исполнения договорных обязательств и контроля SLA в логистике и 3PL.

Статус: **ранний MVP (инициализация проекта)**.

## Документация

Доменная логика и ключевые решения описаны в папке `/docs` (считайте её источником истины).

## Запуск API (пока только каркас)

```bash
dotnet run --project src/Fixon.Api
```

Health-check:

`GET /health` → `OK`

## Frontend (SPA)

Frontend лежит в `frontend/`.

Минимальная i18n-конвенция:
- **Все новые пользовательские строки** добавляйте в `frontend/src/i18n/*`.
- В компонентах/страницах используйте `import { t } from '../i18n'` и берите строки только из `t`.
- Не хардкодьте user-facing текст прямо в React-компонентах.
